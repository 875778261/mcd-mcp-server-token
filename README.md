# 麦麦健身餐搭配官 mcd-fitness-meal

> 报出你的身体数据和一个训练目标，这个 Skill 会在麦当劳中国真实在售的 160 款餐品里，
> 用营养成分数据解出一份**刚好卡住热量与蛋白目标**的套餐，并告诉你差多少、怎么补。

---

## 这个 Skill 解决什么

健身和麦当劳是天然冲突的两件事。减脂期路过麦门店，想吃又怕热量超标；增肌期想吃，
又怕蛋白不够、油太多。通用大模型给的建议几乎都是「鸡胸肉沙拉」「少吃薯条」这类
**正确的废话** —— 因为它不知道麦当劳今天到底在卖什么，也不知道巨无霸到底多少大卡。

本 Skill 的差异点：**不做通用建议，只在麦当劳真实菜单的 160 个 SKU 上做数值求解。**

| 维度 | 通用大模型建议 | 本 Skill |
|---|---|---|
| 菜单来源 | 凭训练记忆，可能已停售 | `list-nutrition-foods` 拉取官方 160 款实时数据 |
| 热量控制 | 「少吃一点」 | 求解器算出具体克数，误差 ≤±5% |
| 蛋白达标 | 「选鸡胸」 | 按 g/100kcal 蛋白密度排序，标注缺口克数 |
| 可执行性 | 建议买沙拉 | 精确到麦当劳实际品名 + 份数 |
| 数据可溯源 | 无法核验 | 每个数字对应官方营养字段，脚本可复算 |

## 核心能力

1. **热量求解** —— 输入目标热量，在真实 SKU 空间内组合出误差 ≤±5% 的套餐
2. **蛋白缺口诊断** —— 增肌目标下算出蛋白差多少克，并给出最高蛋白密度补齐路径
3. **钠预警** —— 健身餐高频高钠，标注单品钠含量，避免「吃完练不动」
4. **预算约束** —— 结合 `calculate-price` 控制单餐花费
5. **真实下单** —— 方案确认后走 `query-meals` / `create-order` 完成点餐

## 数据依据

营养数据来自麦当劳 MCP Server 的 `list-nutrition-foods` 工具，返回官方字段：

```
energyKj, energyKcal, protein, fat, carbohydrate, sodium, calcium
```

实测 160 款餐品，其中蛋白 ≥20g 的有 26 款，低钠（≤500mg）的有 111 款。
数据集快照见 [`references/nutrition-foods.json`](references/nutrition-foods.json)。
